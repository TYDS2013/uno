功能特性

从经典规则到创新玩法，为你提供完整的 UNO 体验

🌐

P2P 联机对战

基于 WebRTC 点对点技术，无需中心服务器。通过 PeerJS 信令服务器建立连接，游戏数据直接在玩家之间传输，低延迟、高隐私。

🤖

人机对战

支持 2-4 人对战，提供简单、普通、困难三档 AI 难度。AI 拥有随机化思考时间和策略决策能力，可在本地离线运行。

🎲

随机匹配大厅

进入大厅后自动匹配，满 2 人即可开局，最多支持 10 人同场竞技。满 4 人立即开始，否则等待 15 秒倒计时。

🏆

成就称号系统

根据连胜场次、UNO 喊话次数、+4 出牌数、被罚抽次数等自动计算称号。包含 13 个成就等级，从新手到王者。

🎴

完整规则支持

支持官方规则与多种村规：+2/+4 堆叠、7-0 规则、强制出牌、+4 质疑判定。房主可自由开关每项规则。

📱

全平台响应式

完美适配手机、平板、电脑。触屏操作优化，键盘快捷键支持（数字键出牌、空格摸牌、U 喊 UNO、K 抓 UNO）。

🚀 快速开始

1

设置昵称与头像

首次打开页面会自动弹出设置窗口，输入昵称并选择一个头像即可开始。

2

选择游戏方式

首页提供三种入口：人机对决（本地对战）、创建房间（邀请好友）、大厅随机匹配（与陌生人匹配）。

3

开始对战

房主点击“开始游戏”，其他玩家等待。手牌中可出的牌会浮起发光，点击即可打出。

💡 提示：创建房间后，点击“复制邀请链接”或“分享”按钮，将房间号发送给好友即可加入。

📜 游戏规则

游戏目标：率先打光自己所有手牌的玩家获胜。

牌面构成：标准 108 张牌，包括数字牌（0-9，四色）、功能牌（禁止 ⊘、反转 ⇄、+2）、万能牌（变色 ★、+4）。

出牌规则：轮到你时，可以打出与弃牌堆顶牌颜色相同、数字相同或符号相同的牌。万能牌任何时候都可打出。

特殊效果：

• 禁止 ⊘：下家跳过回合
• 反转 ⇄：出牌方向颠倒
• +2：下家摸 2 张并跳过
• 变色 ★：出牌后指定接下来继续的颜色
• +4：指定颜色，下家摸 4 张并跳过

UNO 规则：当你打出倒数第二张牌、只剩 1 张时，必须立即喊“UNO”。有 2 秒保护期，期间对手不能抓你。保护期过后若还没喊，对手可以“抓 UNO”，你罚摸 2 张。

🎮 游戏模式

单局制：一局定胜负，先出完手牌者获胜。

累积 500 分：每局结束后，赢家按输家手牌分值计分（数字牌按面值、功能牌 20 分、万能牌 50 分），累积到 500 分宣布最终胜利。

淘汰制：每局结束后，手牌分最高的存活玩家被淘汰进入观战，最后剩下的玩家获得最终胜利。

村规开关：房主可在房规面板中开启以下规则：
• +2/+4 堆叠：允许同类牌叠加，罚抽累加
• 强制出牌：摸到能出的牌必须打出
• 7-0 规则：打出 7 可与指定玩家交换手牌；打出 0 全员按方向传递手牌
• +4 质疑：关闭后 +4 直接罚抽 4 张，不弹质疑窗

📦 部署指南

本项目为纯前端应用，无需后端服务器即可运行。部署非常简单：

方式一：GitHub Pages（推荐）
1. 将 index.html、style.css、app.js 三个文件上传到 GitHub 仓库
2. 进入仓库 Settings → Pages
3. Source 选择 main 分支，保存
4. 等待 1 分钟，获得 https://你的用户名.github.io/仓库名/ 链接

方式二：Netlify Drop
将整个文件夹拖拽到 app.netlify.com/drop 即可获得临时域名。

方式三：Vercel
连接 GitHub 仓库，自动部署，支持自定义域名。

💡 提示：游戏依赖 PeerJS 信令服务器建立 P2P 连接。如 PeerJS 官方服务器在国内访问不稳定，可在设置中配置备用 Render 信令服务器地址。

关于 UNO

v0.5 Beta · WebRTC P2P 架构

UNO 是一款基于 WebRTC 点对点技术的开源卡牌游戏。它不依赖中心服务器，所有游戏数据直接在玩家浏览器之间传输，保证了低延迟和隐私安全。

项目采用纯前端技术栈：HTML + CSS + JavaScript，使用 PeerJS 作为信令服务器建立连接，Socket.IO 风格的通信协议管理游戏状态。支持人机对战、房间联机、随机匹配三种玩法，并内置了成就称号系统和完整的 UNO 规则引擎。

本项目仅供学习和娱乐使用，完全免费，无广告，无内购。代码开源，欢迎贡献。
